# Paper fonts

Unmodified Microsoft Core Fonts for the Web files are included with their complete accompanying EULA. Font notices and licensing remain separate from the project source license. The paper uses Times New Roman for the ablation and Arial for the decoder comparison; these files make rendering independent of the host font installation. All 30 font files in the installed distribution are preserved.

`manifest.json` records each font checksum. The renderer verifies and registers these local files before selecting the paper font families. Apple M4 plots use Matplotlib’s DejaVu Sans family.
